# 🌴 HH Goa Builder Passport

> Turn your photo into your own Hacker House Goa 2026 identity.

A Goa-inspired **Builder Passport** created for **Hacker House Goa 2026 #FrameInGoa**.

Upload your photo, choose an edition, and get a collectible Builder identity with unique visuals, Builder ID and more.

## ✨ Features

- 📸 Photo upload
- 🪪 Builder Passport
- 🌴 Goa-inspired card editions
- ✨ Smooth animations
- 📱 Mobile responsive
- 🖼️ PNG export
- 𝕏 Share to X

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js
- Canvas
- Vercel Blob

## 🚀 Run Locally

```bash
git clone https://github.com/dimcodes09/hh-goa-id.git
cd hh-goa-id
npm install
npm run dev
````

Open `http://localhost:3000`
